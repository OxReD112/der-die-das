Пометка **(Н-номер)** — вопрос в раунд 1 формы носителю (список — §13). До ответа действует то, что написано.

## 0. Главное правило турецкого: аффикс только там, где форма заранее известна

Турецкие падежи и предлоги — это **аффиксы** (*ev-e, ev-de, ev-den*), и их форма зависит от гласных слова (гармония) и от последней согласной. К немецкому слову читалка аффикс не приставит, а при ручном переводе легко ошибиться. Поэтому:

| что | правило | примеры |
|---|---|---|
| место `{0}`, `{1}` в шаблонах (читалка, интерфейс) | **аффикс к `{0}` не приставляем никогда.** `{0}` стоит отдельно: перед турецким «словом-обёрткой» с аффиксом, перед послелогом, после двоеточия, в скобках | `{0} kelimesinin küçültmesi`, `{0} ile ilgili`, `eski yazım: {0} = {1}`, `“{0}” harfi` |
| немецкие слова и примеры в заметках (любые, их тысячи) | так же: без аффикса, через слово-обёртку | *Haus kelimesi*, *laufen fiilinden*, *Kısaltma, açılımı: X* |
| **закрытый список немецких названий** — падежи, времена, разделы приложения | можно апостроф + аффикс, **только формами из таблицы §0а** (не подбирать заново) | *Dativ'de, Akkusativ'i, Perfekt'te, Wortschatz'a ekle* |
| немецкие названия, где чтение неясно (с цифрой: *Partizip II, Futur I, Konjunktiv II*; из двух слов) | только через обёртку | *Partizip II biçimi*, *Konjunktiv II ile*, *Futur I zamanında* |
| числа в `{0}` | без аффикса: порядковое — точкой, «на столько-то» — отдельным словом | `{0}.`, `{0}. kez`, `{0} dakikalık`, `{0} buçuk` |
| турецкие слова-термины (строчные: *artikel*, *modal*) | аффикс обычный, без апострофа | *artikelsiz*, *artikelle*, *modal fiiller* |
| имена людей и мест в переводах предложений (живой турецкий текст) | как в обычном турецком: апостроф + аффикс (решение Алёны 27.11) | *Anna'nın*, *Berlin'e*, *1 Mayıs'tan* |

Было в черновике 1: падежи только через обёртку (*Dativ hâlinde*). «Турецкая Worterbuch» предлагает апостроф (*Dativ'de*): так пишут турецкие учебники немецкого, у всех четырёх падежей одна гармония (*-iv*), а в словаре таких мест сотни. **Взято предложение «Турецкой Worterbuch»**, но только для закрытого списка из §0а — тогда формы проверяются по таблице, а не на слух.

**Решения Алёны (27.11, 17:33):**
1. Обёртка **kelime** разрешена: *{0} kelimesinin*, *{0} kelimesinden* — аффикс на турецком слове рядом, на `{0}` — нет. Где можно — двоеточие или скобки.
2. Названия разделов в постоянных подписях — с апострофом по таблице §0а (*Wortschatz'a ekle*): слово в подписи постоянное. Если название приходит через `{0}` — только через соседнее слово (*{0} bölümüne*).

## 1. Что не переводится

- Немецкие слова и примеры (в `<i>…</i>` и без), пробелы `{{c1::…}}`, теги, места подстановки, «→», «/», «·».
- Немецкие грамматические термины, которые RU оставляет по-немецки: *Präsens, Präteritum, Perfekt, Plusquamperfekt, Futur I / II, Partizip I / II, Konjunktiv I / II, Imperativ, Infinitiv, Plural, Singular, Passiv, Zustandspassiv, Wechselpräposition, sich, trennbar / untrennbar* — с заглавной; аффикс — только по §0а.
- **Немецкие падежи — всегда по-немецки**, даже если RU пишет «дательный» (184), «винительный» (29), «родительный» (19): *Dativ, Akkusativ, Genitiv, Nominativ* (*Dativ'de, Akkusativ'i*). Турецкие названия падежей — только о турецком падеже (§6).
- «дат. п. / вин. п. / род. п.» → *Dat. / Akk. / Gen.*; «(D)» в шаблонах — как в исходнике.
- Названия разделов: *Wortschatz, Wörterbuch, Bibliothek, Notizbuch, Partikeln, Artikel, Verbformen, Modalverben, Pronomen, Präpositionen, Meine Wörter, Einstellungen…* (немецкие надписи не переводятся ни на какой язык).

## 4. Управление: «что-либо, кого-либо» (≈ 5 500 мест)

Турецкий ставит дополнение **перед** глаголом и показывает падеж самим словом. **Падеж — по турецкому глаголу, не по русскому:** *birini beklemek, birine yardım etmek, bir şeyden korkmak*.

| RU | сколько | TR |
|---|---|---|
| что-либо | 1 479 | **bir şeyi / bir şey** (по глаголу) |
| кого-либо | 916 | **birini** |
| чего-либо | 647 | **bir şeyden / bir şeyi** (по глаголу) |
| кому-либо / чему-либо | 496 / 444 | **birine / bir şeye** |
| чем-либо / кем-либо | 960 / 423 | **bir şeyle / biriyle**; «о чём-либо» → *bir şey hakkında* |
| где- / куда- / откуда-либо | 115 | **bir yerde / bir yere / bir yerden** |
| кто-либо / какой-либо / когда-либо | | **biri / herhangi bir / hiç** (в вопросе), *bir zaman* |

- В переводе карточки — словами, без скобок: *birini beklemek* (как RU «ждать кого-либо»), а не аффиксом по-словарному (*-i beklemek*) **(Н6)**.
- `complements[].note` — турецкое управление для этого значения, даже если в RU голое «кого-либо».
- **Перевод немецкого предлога** (Fester Kasus и др., 27.11): турецкий послелог или аффикс в словарной записи — **с падежом через дефис**: *-e kadar, -in yerine, -den sonra, -e göre, -in sayesinde, -i göz önünde bulundurarak*; послелог без падежа — как есть (*için, boyunca, sırasında*). Разные предлоги — разными кусками (*aufgrund — -e dayanarak*, *anhand — -e bakarak*; *statt — -in yerine*, *anstelle — -in yerine, -in yerini alarak*).

«Турецкая Worterbuch» предлагала для примечания *not*. Оставлено *açıklama*: *not* уже значит заметку пользователя в Notizbuch, а в одном окне могут быть обе (как у польского *uwaga* ≠ *notatka*).

## 8. Женские формы

RU «(женщина)» — 147, EN «(female)» — ≈ 500; решаем **по немецкому -in**. В турецком женских форм почти нет:
- есть отдельное турецкое слово в этом значении (*Königin* → *kraliçe*, *Tante* → *hala / teyze*) — пишем его;
- нет — общее слово + **(kadın)**: *Lehrerin* → *öğretmen (kadın)*; в примерах — просто *öğretmen* (или *kadın öğretmen*, если без этого теряется смысл). Формы с *hanım* (*öğretmen hanım*) — это обращение, не название; не ставим.

## 9. Partikeln — система меток (не на утверждение сейчас)

## 11. Числа, письмо

- Порядковое цифрой — **точка**: *5.* (не *5'inci*); «в 5-й раз» → *5. kez*; «17 часов» → *17.00*.
- Дробная часть — запятая (*1,5*), тысячи — точка (*10.000*) — в наших текстах; числа в немецких примерах и в `{0}` не трогаем.
- Процент — **знак впереди**: *%50* (если появится в тексте).
- Правописание — по словарю TDK, со знаком долготы, где TDK его пишет: *hâl, hâli, kâğıt, resmî, edebî, zekâ*.
- Глагол в переводе слова — словарная форма на *-mak / -mek*; существительное — в именительном.
- Буквы **İ / ı**: пишем как есть (*İngilizce, İpucu, ılık*), следить в начале значений и примеров. Если на странице заглавные выходят без точки (*I* вместо *İ*) — **не обходить переводом**, сообщить главному чату языков (см. журнал: уже найдено).
