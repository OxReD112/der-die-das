This is a translation projection into partitioned JSON (same layout as the Russian dictionary in `open data/dictionary-de-ru-json`), built by `deutsch-home/lang/tools/convert_kaikki_dictionary.py`. Selected source fields (glosses, id, tags, raw_tags, form_of, examples) are kept byte for byte; omitted fields are listed in manifest.json. The original JSONL is the complete source.

Added by the conversion (texts unchanged): display status of each sense (translation / form description / reference «zob.»); style, region and subject labels as codes, taken from the source's separate tag fields (`labels`); proper-name kind (`name_like`); reflexive use and case (`reflexive`); separable / inseparable reading and transitivity of verbs from the entry's marks; German syntax lines (`syntax`); a cleaned display text (`shown`) where Kaikki left gaps or a label at the start of a gloss; the part of speech aligned with the English dictionary's inventory (original kept in `source_pos`).

The data is used only to show translations of words already resolved by the app; it never changes how a word is resolved. No audio is redistributed.
