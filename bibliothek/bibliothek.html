German–English Dictionary

Dictionary data is derived from Wiktionary contributors, extracted via Kaikki.org, and distributed in this application using the German–English SQLite dataset provided by Lector.

The dictionary data is licensed under the Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0) License.
